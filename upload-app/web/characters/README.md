The official pages identify these packs as CC0, available for personal and
commercial use. The official Google Drive downloads reported quota exhaustion.
The identical named asset files were obtained from this public mirror at pinned
commit `ff45d4b77af3d258e17217350d0ed5c93a21eab5`:

https://github.com/ChrisF29/ReadyOrNotGame-Project-2025/tree/ff45d4b77af3d258e17217350d0ed5c93a21eab5/NPCs/NPCs

Only the character assets are reused; no code from that repository is included.
`upload-app/scripts/pack_characters.py` retains the Idle clip, prunes unused
accessors/buffers, and packages each source as GLB. No network fetch is made by
the deployed viewer for these characters. They represent generic adults, not
people identified in user footage.
